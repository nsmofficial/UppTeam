1. Executive Summary & Prototype Scope

The AEC Drawing Intelligence Prototype is a complete, operational Python software system engineered to automate the cross-referencing and constructability discrepancy detection across commercial architectural drawings, structural sheets, MEP packages, CSI MasterFormat specifications, and Bill of Quantities (BOQ) spreadsheets.

Core Capabilities Demonstrated: Direct vector PDF ingestion (<1s runtime) • Cross-discipline property graph linkage • Deterministic dimension, quantity, and load check engines • Anti-hallucination Evidence Gate verification • Native Bluebeam vector markup PDF export • Excel QC issue log generation • Autodesk Construction Cloud pushpin JSON export • Streamlit human-in-the-loop review dashboard.

6. Human-in-the-Loop Review Dashboard Operations

The Streamlit web application (ui/review_app.py) provides an interactive portal for project engineers to review and action AI findings before distribution:

  • Multi-Discipline Triage: Filter findings by Severity (High, Medium, Low), Tier (Confirmed, Probable, Needs Review), and Discipline.
  • Dynamic Bounding Box Viewer: Selecting any finding instantly clips and displays the source PDF drawing snippet and specification paragraph.
  • Engineering Sign-Off: One-click Accept, Reject with mandatory rationale code, or append contractor notes.
  • Immutable Audit Trail: Every decision is recorded in out/review_log.jsonl with user timestamp and reasoning.
