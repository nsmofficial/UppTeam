1. Executive Summary & Evaluation Framework

Automated AEC quality control cannot operate on probabilistic 'best-effort' claims. A single hallucinated dimension or missed structural conflict directly triggers job-site change orders, structural rework, and legal liability. This document establishes the formal evaluation methodology, benchmark results across 46 commercial project sets, deterministic anti-hallucination guardrails, and production telemetry protocols.

Core Evaluation Thesis: Multi-Tiered Benchmarking (Extraction, Discrepancy, Evidence Gate, Abstention, Production) • Decoupled deterministic rule verification from bounded LLM semantic reasoning • Physical coordinate re-clipping enforces 100% evidence provenance.

4. The 5 Pillars of Hallucination Prevention

  • Pillar 1: Physical Coordinate Re-Clipping: Every citation is re-clipped at (sheet_no, x0, y0, x1, y1). 1,509 anchors evaluated; 1,506 verified; 0 unverified claims published.
  • Pillar 2: Dual-Anchor Proof Contract: Cross-discipline findings require ≥2 independent coordinate anchors across drawings and specs.
  • Pillar 3: Deterministic Calculation Supremacy: Dimensions evaluated using Python rational Fraction arithmetic; zero LLM arithmetic permitted.
  • Pillar 4: Ambiguity Abstention Protocol: Deliberate drafting traps ('TYP.' tags without count) safely abstained: 20/20 routed to Needs Review, 0 hallucinations.
  • Pillar 5: Run-to-Run Determinism & Negative Controls: 5 clean sets produced 0 false positives; repeated runs produced byte-identical SHA-1 fingerprints.

5. Adversarial Red-Teaming & Injection Testing

Adversarial Test 1: Injected Hallucinations (25 Fabricated Claims)
A mock LLM injected 25 plausible but fake conflicts across 5 spec sections. 25 of 25 (100%) were caught and quarantined by the Evidence Gate. Catch rate: 1.0.
Adversarial Test 2: Real Quotes with False Claims ("The Semantic Sneak")
5 real quotes attached to false claims were injected; 3 passed the coordinate check as tier Probable. This proved that coordinate verification validates text existence, not semantic claim truth.
Architectural Mitigation: All LLM semantic findings are strictly capped at Probable / Needs Review and require Human-in-the-Loop review before export.
